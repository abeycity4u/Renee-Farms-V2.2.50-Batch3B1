V2.2.48 Inventory Category Financial Type
-----------------------------------------
Decision:
- Stock purchase -> Inventory.
- Non-stock/service spending -> Expense.
- Inventory Category remains farmer-defined.
- Financial Type is selected once on the Inventory Category and inherited automatically by its items/future receipts.
- Feed and Medication/Vaccine are no longer selectable for NEW manual Expense records. Historical records remain supported.
- Fuel/Energy remains Expense, not an Inventory Financial Type.

Category Financial Types:
- Feed
- Medication / Vaccine
- Supplement
- Consumables
- Equipment / Tools
- Spare Parts / Maintenance Materials
- General / Other Stock

Data integrity:
- Stock transaction financial classification remains a historical snapshot.
- Changing a category Financial Type updates current items for future receipts but does not rewrite old stock transactions.
- Feed usage (Layer/Broiler/Ruminant Feed) must belong to a category whose Financial Type is Feed.
- Migration 026 infers existing category types from current Batch 2 item classifications; owners can correct a category from Manage Categories if historical setup was mixed.

Deployment:
1. Upload package.
2. Run: php scripts/run_migrations.php
3. Run: php scripts/verify_v2248_inventory_category_financial_type.php
4. QA Manage Categories, Add Item, Update Stock, and all three Expense pages.

Documentation policy:
- Keep only RELEASE_NOTES.txt and BATCH_NOTES.txt at project root for release/batch notes.
- Append future notes to these files; do not create version-specific note files.

Ruminant Sale -> Explicit Animal Exit Outcome
---------------------------------------------

- Explicit Sold live projects Active -> Sold.

- Deleting a sale uses the same conservative lifecycle reversal rule.
- Animal Profile now exposes sale-linked exit history for auditability.
